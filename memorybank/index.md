# OneDegree Finance - Memory Bank Index

## Project Overview
Telegram mini app for Cambodian SME owners to track income, expenses, and profitability.
- **Stack**: Backend (Hono + Bun + PostgreSQL), Frontend (React + Vite + TypeScript + Tailwind), Auth (Telegram WebApp).
- **Core Entities**: Accounts, Categories, Companies, Inventory, Payables, Receivables.
